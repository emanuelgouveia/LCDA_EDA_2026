# 6. Time Series

1. Choose one of the time series datasets.
2. Fill any missing values, if applicable.
3. Visualize one/some of the time series. If necessary for a clear visualization, resample the time series to a more suitable frequency.
4. Are there any patterns, such as trend, cycles or seasonality?
5. Make a visualization comparing different seasonal periods. If you didn't find any seasonality, choose the period you find the most interesting.
6. Compute the autocorrelation function for a time series. Does it confirm what you concluded from visualization?
7. Decompose the time series. Does the importance of each component match your previous analysis?
